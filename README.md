# あかちゃんあそび

生後6ヶ月ごろの赤ちゃんと、おうちのかたが**一緒に短時間**あそぶための知育Webアプリです。

https://tmurata0612-cell.github.io/baby-asobi/

## あそび

- **たっぷ** — 画面にさわると色と音が出る（因果関係あそび）
- **いないいない ばあ** — どうぶつが「ばあ！」（対象の永続性・予測あそび）
- **おと あそび** — たいこ・すず などの音あそび（聴覚あそび）

## 設計方針

- アプリは「親子のやりとりのきっかけ」。おうちのかた向けの声かけヒントを画面に表示します
- 約5分で「おしまい」画面が出ます（区切りの提案）
- 点滅・大音量なし。設定は2秒長押しのペアレントゲートの先だけ
- 画像・音はすべて自作（SVG描画・Web Audio合成）。外部素材・トラッキング・個人情報収集は一切ありません

## 技術

- 依存ライブラリなしの vanilla HTML/CSS/JS 1ファイル構成
- PWA（ホーム画面追加・オフライン動作対応）
